# Skyline

Skyline is a calm, glassy front page for Helium-style browsers: local time, a DuckDuckGo search, an RSS-powered tech feed, rotating artwork, and a compact AI news companion.

## Run locally

```bash
npm install
npm run dev
```

Add `VITE_OPENROUTER_API_KEY` to a `.env` file to activate Signal, the optional OpenRouter-based companion.
